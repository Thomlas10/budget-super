Bienvenue sur l'application **Budget-Super** ! Ce projet fait suite à l'application Budget Manager et intègre de nouvelles technologies comme **SDD Spec Kit** et **Claude AI Superpower**.

## Installation et Lancement Local :
Pour cloner le projet et lancer le serveur de développement local instantanément, suivez ces étapes :

### 1. Cloner le repo :
`git clone https://github.com/Thomlas10/budget-super.git`

### 2. Accéder au dossier du projet :
`cd budget-super`

### 3. Lancer le serveur de développement local :
`npm run dev`
